# 后续交付工作约定

- 完成一个可交付阶段后，使用 AskUserQuestion 的选项形式询问下一步，而不是未经请求自行扩展目标或取消任务。
- 每次完成后，将已验证的交付物上传到用户指定的 GitHub 仓库 FanZeros/540；仓库已有内容时使用新分支，不覆盖旧分支。
- 不把访问令牌写进代码、日志、文档、Git remote 或提交。若授权失效，如实报告并请用户更新凭据，不绕过权限。
- 所有自主创建的文件、测试结果和依赖留在当前项目目录；不更新用户主目录中的持久记忆，以遵守本项目禁止目录外写入的约束。

**原因：** 用户明确要求持续交付、保留证据、选项式决定下一步，并要求不写项目目录之外。

**应用方式：** 阶段完成后先报告实际验证结果、上传结果及已知限制，再通过选项询问下一步。无法验证或被权限阻止的动作不得假称完成。
