# 自测命令约定

真实引擎与自测依赖只安装在 `tests/runtime/`，输出只写 `tests/output/`。运行前把 `HOME`、`XDG_CACHE_HOME`、`XDG_CONFIG_HOME`、`TMPDIR` 指向本项目的测试目录。

本项目以官方 `UrhoXRuntime` 实际执行 Lua 与 NanoVG 渲染，不启动开发服务器。自动输入脚本只产生与固定键位等价的动作，不修改血量、位置、敌人存活状态。

`initial_*` 是素材生成完成前的首次试跑，明确记录了资源尚未生成的失败；保留用于复现，不作为最终通过证据。`scene_*` 为完整素材的剧情开始页；`play_*` 为第一关实玩、1倍速回放、进入第二关的实际运行证据。截图保存时软件渲染器出现的 frame time spike 必须单独记录，不能隐藏原始 FAIL，也不能把它误称 Lua 错误。

其余最终检查结果以 `自测报告.md` 列出的命令和报告为准。
